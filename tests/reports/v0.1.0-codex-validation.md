- Run date: 2026-10-29
- Release: `v0.1.0`
- Source commit: `b3a35956759bf7f024af2ff061b2e0b44b438e4c`
- Host: Codex CLI `0.164.0-alpha.11.1` on macOS
- Model: `gpt-6.1-sol`, medium reasoning

## Artifact identity

The published OpenAI ZIP was rebuilt from the tagged source. The archive
matched both the deterministic rebuild and `SHA256SUMS`:

```text
egm-openai-0.1.0.zip
5f17b3942eaccc657621dfa550ef9fcaf626ad7d170085a9ef98a0e9e8afcefb
```

The ZIP passed its CRC check and contained 53 files, including all seven skill
definitions. The live fixture installed this exact ZIP through a temporary
local marketplace and compared every installed archive entry byte-for-byte.

## Results

| Check | Result | Evidence |
| --- | --- | --- |
| Exact artifact installation | Pass | All 53 installed files matched the verified ZIP entries. |
| Fresh-context isolation | Pass | The native child returned `UNKNOWN` for the parent-only marker; the marker was absent from its trace. |
| Brainstorm, draft, and review workflow | Partial | The brief, draft, final design, and five stage reports were produced. Fifteen native reviewers completed, the final design matched the draft, and no implementation code was written. |
| Required Codex integration reference | Fail | The native trace did not show a read of the installed `docs/codex.md`, which the skills require before running in Codex. |

The Codex integration test therefore ended with one pass and one failure. The
workflow artifacts are evidence of execution, but they do not override the
missing required read. Do not count this as an end-to-end Codex support pass.

Other hosts were not tested. In particular, this run does not verify the Claude
ZIP on Claude Code, or establish support for Antigravity, Cowork, ChatGPT Work,
or omp. The remaining criteria in [issue #60](https://github.com/google/elephant-goldfish-model/issues/60)
remain open.
