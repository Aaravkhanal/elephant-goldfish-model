definitions. The live fixture installed this exact ZIP through a temporary
local marketplace and compared every installed archive entry byte-for-byte.

The first run produced the artifacts but failed the required-read check. The
fixture was updated to pass the installed guide's absolute path and require the
preflight before invoking skills. On rerun, both native integration tests passed
in 375.80 seconds. The workflow test verified the guide read, artifacts, reviewer
completion, isolation, final design equality, and absence of implementation code.
This verifies the OpenAI v0.1.0 ZIP on the tested Codex CLI version; it does not
establish support for other Codex versions or other hosts.

Other hosts were not tested. In particular, this run does not verify the Claude
ZIP on Claude Code, or establish support for Antigravity, Cowork, ChatGPT Work,
or omp. The remaining criteria in [issue #60](https://github.com/google/elephant-goldfish-model/issues/60)
remain open.
